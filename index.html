bpod-gui

A Python package that provides a set of standardized GUIs for interacting with the Bpod Finate State Machine from Sanworks.

This package is intended to be utilized alongside the bpod-rig package which can be found here

bpod-gui is currently being developed and maintained by Austin Pauley from the Olfactory Behavior Lab at Florida State University.

Included GUIs

  1. Simple Launcher

  2. Manual Control Interface

  3. Water Solenoid Calibration Interface

  4. Protocol Selector

    1. Subject Manager

    2. Experiment Selection

    3. Experiment Settings/Configuration Selection

  5. Configuration Interface

  6. Live Experiment Data Output
